# sales-dashboard-excel-project
Interactive Excel Sales Dashboard analyzing retail performance using Power Query, Pivot Tables, and dynamic visualizations.
📊 Excel Sales Dashboard Project
📝 Overview

This project presents an interactive Sales Dashboard in Microsoft Excel built using a retail Superstore dataset. The objective is to analyze business performance, uncover sales trends, and provide actionable insights through dynamic visualizations.

The project demonstrates end-to-end data analysis — from data cleaning to dashboard creation — making it suitable for entry-level data analyst portfolios.

🎯 Objectives

Analyze overall sales and profit performance

Identify top-performing products and categories

Track regional and segment-wise sales trends

Build an interactive dashboard for quick business insights

Practice real-world Excel data analysis workflow

🗂️ Dataset Features

The dataset includes the following key fields:

Order ID

Order Date

Ship Date

Customer Name

Segment

Region

Category & Sub-Category

Product Name

Sales

Quantity

Discount

Profit

🛠️ Tools & Techniques Used
🔹 Data Preparation

Power Query for data cleaning and transformation

Removed duplicates and handled missing values

Standardized data formats

🔹 Data Analysis

Pivot Tables

Calculated KPIs (Sales, Profit, Quantity)

INDEX & MATCH / VLOOKUP

Profit margin analysis

🔹 Dashboard Development

Interactive slicers

Pivot charts

KPI cards

Dynamic filtering

📈 Key Insights

Identified top revenue-generating categories

Compared regional sales performance

Analyzed impact of discounts on profit

Highlighted monthly sales trends

Found high-performing customer segments
